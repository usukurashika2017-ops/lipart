# 馬込沢うすくら歯科 リップアートメイク特設ページ

GitHub Pagesにそのまま公開できる静的ホームページです。

## ファイル構成

- `index.html`：ホームページ本体
- `assets/css/style.css`：デザイン
- `assets/images/`：掲載画像
- `.nojekyll`：GitHub Pages用設定

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内のファイルをすべてアップロードします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Build and deployment` の Source を `Deploy from a branch` にします。
5. Branchを `main`、フォルダを `/(root)` にして `Save` を押します。
6. 数分後に表示されるURLをInstagramプロフィールのリンクに設定します。

## 内容を変更する場所

文章・料金・電話番号は `index.html`、色や文字サイズは `assets/css/style.css` で変更できます。
画像を差し替える場合は、`assets/images` 内の同名画像に置き換えるとレイアウトを保てます。
